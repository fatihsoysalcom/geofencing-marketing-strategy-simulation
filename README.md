# Geofencing Marketing Strategy Simulation

This Python script simulates the selection of a GEO marketing partner. It models partners with varying expertise and transparency scores and evaluates their potential campaign success and ROI for a hypothetical South Korean market entry. The simulation highlights how these factors influence outcomes.

## Language

`python`

## How to Run

Save the code as `geo_marketing_sim.py` and run it from your terminal using `python geo_marketing_sim.py`.
